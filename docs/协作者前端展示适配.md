# 协作者前端展示适配

来源：[mili-bohack2026 的 new 分支](https://github.com/1981819971/mili-bohack2026/tree/new)，提交 `61b5e1d1fa37c92560042bf638a1d8992ca764ff`。

以该分支相对 `main` 的 `app/app.js`、`app/app.css` 增量为依据，三方合入本地当前源码，保留本地之后的修改。没有整文件替换成远程版本，也没有修改原生自动操作流程。

## 展示与适配

- 老人端：说话键更宽、更高；守护、设置、回话字号加大。回话保留两行，矮屏允许形象区域收缩，避免文字被裁掉。
- 等待反馈：思考时显示“米粒在想，请稍等”，2.5 秒后显示“马上好，再等一下”；状态结束时恢复原提示。上一句气泡的清理计时器不覆盖新一轮的在想、在听状态。
- 家人端：守护页显示体征提醒、防诈骗摘要、最近活动时间；健康页显示服务端血压和血糖。未配对、网络失败、没有测量记录分别显示；体征接口失败不显示为“老人还没量过”。
- 数据读取：概况、体征、动态并行读取，单次请求最多等待 10 秒；退出或换账号后忽略旧回复。适配现有服务端中文的未配对原因。
- 防诈骗摘要：沿用现有原生 `scamLog()` 和 `/act` 接口，只同步风险等级与时间，不上传短信内容和号码。摘要不算作老人主动活动；换号后不继续同步旧号积压，进度不进入跨设备配置备份。
- 主动发送体征信息：服务端确认收到后才显示发送成功。

此次以展示和必要的数据衔接为范围，体征上报仍沿用原有通道，没有引入分支中的独立体征补传队列。微信、抖音点击流程、语音识别、记忆模块及半透明操作提醒保持本地当前实现。

- 页面验证使用本地服务和模拟接口，没有连接真实账号、调用真实模型或发送真实消息。
