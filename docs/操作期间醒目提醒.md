# 操作期间醒目提醒

采用醒目提示和一次语音提醒，减少老人不知道任务仍在执行而触碰手机的情况。

## 显示方式

- 参考用户提供的首页截图：卡片水平居中，中心位于从屏幕顶部往下约三分之一处。
- 沿用首页的紫色主色 `#5B4DF0` 与深紫色 `#4A3CD8`。背景为椭圆形径向渐变：中心文字区域约 92% 不透明，外圈逐步减淡，最外缘完全透明；去掉描边和阴影硬边。
- 提示最大宽度 336dp，左右至少留出 24dp。只显示“正在操作”“别动屏幕”两行 32sp 白色粗体大字，居中排列，不显示品牌小字、联系人或具体任务内容。
- 使用已有无障碍服务的 `TYPE_ACCESSIBILITY_OVERLAY`，无需新增权限；无障碍未开启时无法显示跨软件提示。
- 提示不接收触摸、不获取焦点，也不参与无障碍控件查找。此方案提醒用户，不能阻止实际误触。

## 接入与收起

共用原生 `OperationNotice` 组件，用独立编号管理每次提示。为兼容原有接口保留标题参数，组件不存储或显示该参数。

| 入口 | 提示生命周期 |
| --- | --- |
| 微信消息、语音、视频、红包流程 | `WxFlow.start` 接单后显示，在原有 `finish` 或 `stop` 时收起；不会在派单接口返回时提前收起 |
| 软件内搜索、视频播放入口、节目直达、电视工具、播放器控制 | 工具注册时统一包装 `run`，同步动作返回或异步 Promise 结束时收起；包含工具内部转调和经验重放 |
| 央视影音延迟切换直播页 | 原生延迟动作单独持有提示，到原有回调执行结束后收起 |

每个编号最多保留 45 秒；无障碍服务解绑或销毁时统一清除。超时仅清除提示，不改变原任务的超时或停止规则。

## 语音

- 微信在原有派单回复中加入“操作时请先别碰屏幕”，不额外叠加一条播报。
- 返回 Promise 的长流程在开始时通过原有语音通道提醒“正在帮您操作，请先别碰屏幕”。同步返回的短动作不额外播报。
- 内部转调和短时间连续执行在 8 秒内不重复播提醒；已播提醒的工具不会再触发原有工具结束后的过程播报。
- 智能体的 `quiet` 参数继续传给工具，静默执行时不播新增提醒。

## 范围与验证状态

未改联系人选择、坐标、原有等待时长、重试或点击顺序，未添加截图识别和触摸拦截。原生异步任务仍按原有完成标准收起提示，提示消失不代表已经核实消息送达或通话接通。

本轮只修改源码并人工检查调用关系，按要求未运行测试、构建或安装，未同步生成的网页及 Android assets。安装包含这些源码的新版本后才会生效。
