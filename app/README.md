# 米粒 · 当前版本说明

> 2026-11-03 凌晨 ｜ 单文件版，双击即开

---

## 怎么打开

**桌面上的「米粒.html」，双击。** 不用服务器、不用联网、不用装任何东西。
（6.6MB，因为 THREE.js、两个模型和贴图全都内联在里面了。）

---

## 现在有什么

**五个页面**

| 页面 | 内容 |
|---|---|
| 家 | 米粒站在白卡片里，三格数据（今天办了 / 学会的事 / 陪你），一个黑色胶囊「说一句话」 |
| 常用 | 把常办的事做成一排按钮：实景导航、微信视频、电视剧大全、CCTV 直播（可切台）、红果短剧、天气、挂号 |
| 办了 | 它替你办过的事，一条一条记着，带时间 |
| 学的 | 成长条 + 六条「它学会的事」，教够 6 条它就长齐 |
| 家人 | 儿子 / 闺女 / 小满，点一下直接拨；底下「按这里 · 叫人来」 |

**两个场景（同一份源码，两份成品）**

| 场景 | 打开方式 | 差别 |
|---|---|---|
| 产品版 | `米粒.html`（默认） | 阈值 0 / 5 / 12，正常用几天才换形态；数据存 `mili` |
| 演示版 | `米粒-演示版.html` 或 `米粒.html?demo=1` 或线上 `/demo` | 阈值 0 / 2 / 4，数据存 `mili_demo`，和产品版完全隔离；首页有「演示版」徽标，点一下能当场「学会一条 / 删一条」，看见它变大变小 |


**说话层**：点「说一句话」从底部弹出 sheet，「我在听」+ 六句常用话，点一句它就去办。

**能办的事**：打电话（会显示拨号中→通了）、看天气、接着看短剧、收红包、防诈骗拦截、提醒吃药、拍照、问日期、出门导航、挂号、寂寞了陪聊。

**三种形态**：刚出壳（雏鸡在蛋壳里）→ 半大 → 长齐了（彩色成鸡）。
它现在多大，取决于它学会了几条。**教一条长一点，删一条缩回去。**

## 演示时能用的地址参数

在地址后面加，比如 `米粒.html?r=6`

| 参数 | 作用 |
|---|---|
| `?mode=product` | 强制产品版（即使成品文件是演示版） |
| `?demo=1` / `?mode=demo` | 演示版（阈值 0/2/4，数据隔离） |
| `?p=hub` | 打开就在「常用」页 |
| `?p=did` | 打开就在「办了」页 |
| `?p=learn` | 「学的」页 |
| `?p=family` | 「家人」页 |
| `?skip=1` | 跳过引导（现场演示用） |
| `?listen=1` | 打开就弹说话层 |
| `?ask=今天冷不冷` | 打开就执行一句话（中文要 URL 编码） |

## 视觉规范（以后所有 App 都按这个来）

- 底：`#F2F2F5` 冷灰
- 卡片：`#FFFFFF`，圆角 24，阴影几乎看不见
- 主文字 `#111114` / 次要 `#8E8E93` / 极淡 `#C7C7CC`
- 主按钮：纯黑胶囊，高 54
- 底部导航：五个线性图标 + 12.5px 字，选中项浅灰胶囊
- 弹层：底部 sheet，圆角 28，顶部一根小把手，右上角圆形 ×
- 字号：大标题 31/700，区块标题 13/灰，正文 15.5-16.5
- **整个界面唯一的暖色，是米粒自己**

## 还没做的

1. **真机 Android 壳**：无障碍记录、悬浮层、语音识别，都要打包成 APK 才跑得起来
2. **心率**：BLE 0x180D 还没接（`android/` 里目前没有蓝牙读心率的代码），等手环充好电再补
3. **语音识别**：网页端是点选预设句；Android 壳里已经接了系统 ASR，真机验证还没做
4. **200 条内容库**：现在只有 12 个场景，要扩到 200

## 文件在哪

- 成品（产品版）：`app\米粒.html`（单文件，可直接发给别人）
- 成品（演示版）：`app\米粒-演示版.html`（打开就是演示场景）
- 线上：`server\index.html` 产品版 · `server\demo.html` 演示版（`/demo` 路由）
- 源工程：`bohack-elder\app\`（index.html / app.css / app.js / data.js / assets / build.mjs）
- 模型：`app\assets\m1-rig.glb`（雏鸡）· `m2-rig6.glb`（成鸡），都带 8 根骨
- 改完跑：`node build.mjs` 会重新生成 `米粒.html`
