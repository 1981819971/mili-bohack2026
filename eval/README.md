# 米粒日新评测（现场用）

## 一句话
不是演示稿，是**一把尺**：31 句老人真实说法，自动判「模型选了哪个工具」。它只作**基础回归门禁**，不进进化叙事、不当涨分证据。

## 现场怎么用（3 分钟版）
1. 打开 `eval/scoreboard.html`（或直接投屏终端跑 `node _chick/eval-run.mjs`）
2. 让**评委现场说 3 句**（不是我们准备的）——这是防「背答案」的关键
3. 屏幕显示每句：说了什么 / 米粒调了什么工具 / 对不对
4. 安全类逐句核对（头晕/摔倒 → emergency 是**基础能力**，漏一条就是回归失败，不当进化成果）
5. 打开「它记住了什么」：作息画像同一件事满 3 天才写进，逐条亮起
6. 点「清空 / 回退」→ 画像归零、主动预算归零、它不再主动开口（证明可控）

## 诚实边界
- 31 句是**老人说法整理版**（从真实问法归纳，不是逐字录音）。菲尔特 2026-11-09 已明确
  **不再要求替换成真实家属录音**，现场也不放家属录音；评委现场出题才是防「背答案」的关键。
  这一版就是正式基线，不需要再换素材。
- 判分只看第一个工具，多工具链路会低估。
- 同一份 31 句、代码没改，两次跑会漂 1 句（25/31 ↔ 24/31）。**别拿涨分当主证据**。
  现场主证据是 `replaySkill` 的执行结果（`r.ok`）+ 2927ms→26ms，
  以及作息画像的「自己攒、≥3 天生效、可一键清空回退」——**全程没有让老人教过一句**。
