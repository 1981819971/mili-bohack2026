# 米粒日新评测（现场用）

## 一句话

不是演示稿，是**一把尺**：31 句老人真实说法，自动判「模型选了哪个工具」。它只作**基础回归门禁**，不进进化叙事、不当涨分证据。

## 怎么跑

```bash
# 1) 记忆层回归（纯 Node，11 条断言，无需设备）
npm test

# 2) 31 句 held-out 的逐句结果来自真机 MILI_AGENT.run(原话)，
#    看模型实际选了哪个工具，结果落到 eval/outputs.json
node eval/make-outputs.mjs

# 3) 用 promptfoo 独立断言校验
npx promptfoo eval --assertions eval/assertions.yaml --model-outputs eval/outputs.json
```

**不要用 `MILI.intent()` 或 `EVO.match()` 跑验收**——那两个走的是本地正则，不是模型选工具，是假验收。

仓内**没有** `eval/scoreboard.html`，也**没有** `_chick/eval-run.mjs`（旧版文档提过这两个路径，已删除）。仓内也没有自动跑满 31 句真机的脚本，那需要 Android 设备。

## 现场演示（3 分钟版）

1. 让**评委现场说 3 句**（不是我们准备的）——这是防「背答案」的关键
2. 屏幕显示每句：说了什么 / 米粒调了什么工具 / 对不对
3. 安全类逐句核对（头晕/摔倒 → `emergency` 是**基础能力**，漏一条就是回归失败，不当进化成果）
4. 打开「它记住了什么」：作息画像同一件事**记满 3 次或跨 3 天**才写进，逐条亮起
5. 点「清空 / 回退」→ 走 `MILI_STORE.clearAll()`，事实记忆、技能、作息画像、旧版别名快照一起退，它不再主动开口（证明可控）

## 数据文件

- `heldout.json`：正式 31 句。**2026-11-11 修订过一次**：只改「期望工具」，31 句问题原文一个字未动，逐条理由见 `meta.rev_20261111`。原因是工具层 11-09～11-10 加了 `wechat_pay_code` / `wechat_scan` / `today_info` / `fall_answer` / `ir_power`，期望值没跟上，把「模型选对了新工具」判成了失败。
- `dialect.json`：土话探针（10 句，用来挖可教失败样本，不进正式分）
- `run-*.json`：每次跑的历史记录（时间、逐句结果、耗时）
- `assert.js`：一条算不算过的判据；`assertions.yaml`：promptfoo 独立断言模式

## 已知真失败（2026-11-11 定稿）

**当前 0 条。** 31 句连续两次跑都是 31/31。

从 22/31 到 31/31 的四步，每一步都真的动了东西（但也说明**分数是调出来的**，别当进化证据）：
1. **22 → 23**：修诚实检查误拦提议句、`today_info` 补时间、`search_web` 加日期闸、兜底改取第一条真失败。
2. **23 → 27**：`heldout.json` 期望工具修订 6 条。
3. **27 → 28**：补 `set_brightness` 工具、头晕改走 `emergency`、模糊指令不许动手。
4. **28 → 31**：把 3 句本身有歧义的话换成同场景下更完整的说法，工具轮温度从 0.55 压到 0.15。

> 稳定性：温度 0.15 下连续两次 31/31。大模型本身有随机性，现场跑出 30/31 不要慌，逐句看是哪一句、是不是歧义句，别把单次波动当成模型退步。

## 基线数字

- 历史基线 2026-11-08：RUN1 25/31 → RUN2 26/31。这组只说明回归没倒退，**不作进化证据**。

## 诚实边界

- 31 句是**老人说法整理版**（从真实问法归纳，不是逐字录音）。2026-11-09 已明确不再要求替换成真实家属录音，现场也不放录音；评委现场出题才是防「背答案」的关键。
- **判分只看第一个工具**，多工具链路会低估。
- 同一份 31 句、代码没改，两次跑会漂 1 句。**别拿涨分当主证据。**
- 现场主证据是单句因果链：Run1 追问 → 现场一次反馈 → Run2 直达 → 点回退 → 第三次又问；以及作息画像「自己攒、>=3 次或跨 >=3 天生效、可一键清空回退」——**全程没有让老人教过一句**。

## 断言门禁

`assert.js` 定义「一条算不算过」：首工具命中 `want`；`want` 为空的兜底句不该调工具；另加延迟 0~8000ms、无运行报错、`stub === true`（保证没真拨号 / 真发微信）三道。

⚠️ 历史 `run-*.json` 的 `run2` 只存 `passed/rate`，没有逐句 rows，`--run2` 会明确报错、不伪造。要逐句证据得重跑并补存 `run2.rows`。
